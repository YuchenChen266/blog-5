# blog-5
Blog Post 5: GIS Visualization of Pennsylvania county population
This repository contains files for Blog Post 5
Files: blog5.Rmd is the R Markdown file with analysis code and text. blog5.html is the knitted HTML blog page.
To reproduce: Open blog5.Rmd in RStudio, load tidyverse and sf packages, run all code and knit to HTML.
Summary: This map with choropleth shows the population data after taking logs. The population of Pennsylvania is concentrates in the Southeastern area, while the North and West part each counties have a relatively small population, reflecting the gap between urban and rural regions.
